# Drama speech types and sound treatments

Gemini Drama identifies narration, spoken dialogue, internal thought, squad-link turns, and chapter titles while preserving the cleaned transcript. Character extraction supplies the cast; **Prepare speaker review** supplies the turn classifications without generating audio.

**Read chapter titles** controls title announcements independently from narration. Choose **Chapter title voice** to use a different Gemini voice, or leave it at **Use the narrator voice**. The option is off by default. Profile settings apply to future recordings; chapter review can save an override and preview its saved title before re-recording. The saved chapter label is announced before the body unless an opening chapter heading is already present. Standalone headings retained inside the transcript are classified as **Chapter title** and use the same setting and voice; turning titles off skips their synthesis while retaining the original text for review. Older automatic assignments can be recognized during recording; prepare speaker review again to refresh their displayed classifications. Explicitly corrected assignments retain the classifications you saved.

A source chunk containing only a skipped title is kept as brief silence, preserving its chapter index without submitting any title text to TTS. Review turn numbers include a separate title announcement when enabled and remain aligned with recording diagnostics.

In a Gemini Drama profile, **Speech type sounds** chooses delivery and sound for each type. Clean voice is the default. CB radio filters and compresses the voice, with optional light static and transmission clicks. Mental link and inner voice add short, subtle reflections. Effect strength blends the treatment with the clean voice. Effects use local FFmpeg processing after synthesis; they do not require another model request or change the assigned voice.

In a chapter's speaker review, correct the speaker or speech type, adjust sounds, preview a turn, and select **Save speaker turns and sounds**. Re-record that chunk to apply the saved choices. Preview requests use the same synthesis direction and audio treatment as recording; changing only effect settings reuses cached clean preview audio during its cache lifetime. Changing delivery, text, cast direction, or voice creates a new sample and can use API quota. Preparing and previewing are explicit actions.

Saved corrections keep text and performance metadata authoritative. The server checks ownership, review revision, current saved text, cast, ordered source coverage, and allowed speech types. Saves are refused during queued/running recording. Recording reuses valid saved direction and stops if explicitly reviewed assignments no longer match the text, profile, or cast. Legacy automatic artifacts can be prepared again. Existing recordings are not changed by saving classifications or profile settings.

Gemini TTS cooldowns are tracked separately for each credential and model. A provider's HTTP 429 retry time carries across a job's segments and chapters and is saved in job settings for scheduled retries. Available independent fallbacks can continue recording. When every choice is cooling down, the worker waits for the earliest eligible choice. The stored cooldown entries contain credential hashes, never API keys.

Successful fallbacks and Director repairs remain in downloadable diagnostics, grouped separately from actual failures. They do not create active review issues. New flags include a turn number and an audio offset measured from PCM duration, including placeholders and effect tails. Legacy flags with no measured offset display an unavailable position rather than treating zero as a known location.

Fresh cleanup batches keep lowercase continuations of incomplete PDF sentences with the preceding fragment. Existing pinned source/chapter mappings are retained. A document excerpt that ends partway through a sentence still needs source review; Narratum does not invent missing words.
